# Avenir Housing — logo files

The logo as used on the website: the rounded roof-and-dot mark with the
wordmark set in **Archivo** ("avenir" ExtraBold 800, "housing" Light 300).
All lettering is converted to outlines, so the SVGs look identical everywhere
without the font installed. `avenir-housing-logos-overview.png` shows every version.

## Which file to use

| Use | File |
| --- | --- |
| Default, on white or light backgrounds | `avenir-housing-logo` |
| On forest green or other dark colour | `avenir-housing-logo-reversed` |
| One colour print, fax, forms | `avenir-housing-logo-ink` |
| Over photos or very dark backgrounds | `avenir-housing-logo-white` |
| Small spaces, stamps, watermarks | `avenir-housing-mark` (+ `-reversed`, `-ink`, `-white`) |
| Social media profile pictures, app icons | `avenir-housing-icon` (cream) or `-icon-green` |

- **SVG** (`logos/svg/`) — for the web, print and design tools (Figma, Illustrator, Canva). Scales to any size.
- **PNG** (`logos/png/`) — transparent background, for Word, PowerPoint, email signatures.
  The number in the file name is the width in pixels (logo: 800 / 1600 / 3200; mark: 256 / 512 / 1024; icon: 512 / 1024).

## Colours

| Name | Hex | Used for |
| --- | --- | --- |
| Forest | `#22543F` | Mark and "avenir" |
| Sage | `#3D6E57` | "housing" |
| Light sage | `#BCD3BF` | "housing" on dark backgrounds |
| Cream | `#F5F4EF` | Reversed logo, site background |
| Ink | `#1B211D` | One-colour version, body text |

## Good practice

- Leave clear space around the logo at least the height of the dot on every side.
- Don't stretch, recolour, rotate, add shadows or outline the logo.
- Minimum size: logo 120px / 30mm wide; mark 16px / 5mm.
